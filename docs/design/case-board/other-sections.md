# How the other sections fit the case board

Case lenses stay **Brief → Space → Evidence → Research → Work → Room → Reports**. With the case board, they become views of the same case data rather than separate tools.

| Lens | Role with the case board |
| --- | --- |
| **Brief** | The written summary: what happened, what you need to prove and its state, their arguments, next step. Generated from the board, editable, every line referenced. Light mode lives here. |
| **Space** | The case board: people, claims, disputed points, place, media, money, leads, strings. Where you think. |
| **Evidence** | Every file and what was found in it. Loose papers, review state, integrity, originals. Opening an item shows where it's used on the board. |
| **Research** | Rules and law: statutes, codes, contract clauses, guidance. Rule cards on the board come from here. |
| **Work** | Tasks and requests: from holes, leads, next steps and Room decisions. Status flows back to the board. |
| **Room** | People talking and calling (see room-and-calls.md). |
| **Reports** | Outputs: letters, bundles, chronologies, handover packs. Written from the board; nothing is sent without a person. |

Open question: whether Brief and Reports, or Work and Room, should merge after real use. Don't merge before the journeys are tested.

Global pages (Home, Cases, New case, Lawyers, Notifications, Settings) are unchanged in role. Home should show "what changed and what's next" across cases, never vanity stats.
