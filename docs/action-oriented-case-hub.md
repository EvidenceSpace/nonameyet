# Action-oriented case hub

The local case library supplements passive counts with one deterministic recommended next step per case. Recommendations are based only on local, user-controlled state and never claim legal urgency or predict an outcome.

The order is:

1. Restore an archived case before editing it.
2. Add the first source record.
3. Review pending AI suggestions against their sources.
4. Confirm important source-linked facts.
5. Refresh an out-of-date encrypted backup.
6. Create a missing encrypted backup.
7. Recheck the organized record before sharing.

Each recommendation links to the relevant case section where possible. It does not automatically change data, confirm a suggestion, upload a file, or create a backup.
