# Source consistency resolution lifecycle

The Chromium consistency lifecycle verifies explicit review of different verified values across separate original records.

The gate requires:

1. Two originals carry separately source-linked agreed-price facts.
2. Different normalized values create one unresolved comparison.
3. Either source can be opened from the comparison card.
4. Saving without a decision is rejected.
5. A user can select one source-linked value and add a local review note.
6. The comparison becomes resolved while both originals and both verified facts remain unchanged.
7. The selected value, note, and resolved status persist across reload.

A detected difference is a review prompt—not proof that either record is wrong. Resolving it records the user's decision without deleting or rewriting source material.
