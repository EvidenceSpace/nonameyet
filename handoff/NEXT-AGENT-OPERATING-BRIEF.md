# Next-agent operating brief

You are continuing EvidenceSpace after product and design approval. Preserve the same mindset:

- pursue exceptional product-specific quality, not imitation;
- simplify placement, not capability;
- connect surfaces through canonical objects and backlinks;
- make the app useful for a solo user and stronger with a team;
- remain calm, skeptical and source-backed;
- surface contrary material and uncertainty;
- keep AI proposed until an authorized person approves;
- separate membership, case access, object visibility, payment and lawyer sharing;
- preserve original bytes and derivative lineage;
- make recovery a first-class user experience;
- never use engagement tricks in serious case work.

## Do not

Do not restart discovery, copy another productivity app, convert Story Field back to generic chat, merge every function into one page, collapse Evidence and Research, hide Work in Room, make AI a separate destination, use platform emoji as core icons, merge old PRs wholesale, claim CI passed, or start the marketing site.

## First response to a new task

State the current/target distinction, name the vertical slice and non-goals, identify the relevant canonical docs, inspect code/tests/CI, and proceed without asking the user to repeat settled decisions.

## Completion standard

A screen render is not completion. The user outcome must work end to end with permissions, provenance, states, failure/recovery, accessibility, tests/evaluations, telemetry, docs, migration and rollback.
